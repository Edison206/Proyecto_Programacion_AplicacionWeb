# LogicWeb UTA — Silabo Interactivo

Aplicacion web didactica para el aprendizaje de algoritmos de programacion en C++.

## Tecnologias
- Django 6.0.3 | Python 3.x | SQLite3
- HTML5 / CSS3 / JavaScript (Fetch API)

## Instalacion
```bash
git clone <url-del-repositorio>
cd Silabo
pip install django
python manage.py migrate
python manage.py runserver
```
